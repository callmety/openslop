# Code of Conduct

**This project is unmaintained and conduct concerns are not actively
monitored or enforced here.** The file is kept in the repo so that
forks which want to keep a code of conduct have a starting point.

If you fork this project and want to run it as a community, the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
is a reasonable default. Wire up your own reporting contact in this
file — do not direct conduct reports at the original author of this
codebase.
